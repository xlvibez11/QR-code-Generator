This is a QR code generator made from javascript with node and the qr-image package.
To use download and unzip it then open your terminal and run this command

cd Downloads/QR-code-Generator/
chmod +x qrgen.sh

After that run the .sh file using this command

./qrgen.sh

it would ask for your URL so just paste it there and click enter then it would make your qrcode in the qr_svg.png file in the folder for your use
Thank you for using my QR code generator
